# Telegram Quiz Bot

Каркас проекта интерактивного Telegram-бота-опросника.

## Стек
- Python
- aiogram 3
- SQLite
- JSON-файлы с викторинами

## Структура
- `app/` — приложение и модули
- `data/quizzes/` — файлы викторин
- `assets/` — статичные изображения
- `tests/` — тесты
- `.env.example` — пример переменных окружения

## Статус
Пока это только структура каталогов и документация. Реализация модулей не добавлена.

## Запуск
Инструкция по установке и запуску будет добавлена после реализации базовых модулей.
